# unicodemaxxer

Get fast at typing equations in Word.

You see a formula, you type it the way you would in a Word equation
(`x\bar=1/n \sum_(i=1)^n x_i`), and the next one comes up. Statistics,
microeconomics and macroeconomics, three levels each, timed or zen. Make a room
and race your friends.

**Play:** https://magnuslundtoft04-dev.github.io/unicodemaxxer/

Made by Magnus and Gregers at CBS.

## Run it locally

```
npm install
npm run dev
```

## Add a formula

Open `src/data/formulas.ts`, add a line to the right subject and level, run
`npm test`.
